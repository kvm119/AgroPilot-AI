# AgriPilot v1.0 Release Notes

Welcome to the official 1.0 production release of the AgriPilot Backend! 

This release graduates the platform from a prototype to an enterprise-grade cloud-native application capable of supporting thousands of concurrent farmers.

## Major Features
- **AI Orchestrator**: Fully connected reasoning engine integrating Weather, Market, Government Schemes, Vision, and Analytics via the Gemini LLM.
- **Vision Intelligence**: Production-ready image processing for Crop Disease Detection and Fertilizer OCR.
- **Offline Synchronization**: The backend now perfectly handles queued offline requests by validating HMAC-SHA256 signatures generated by the Flutter client.
- **Enterprise Security**: Complete PII redaction, strict RBAC, and tamper-evident cryptographic audit logs.
- **Production Infrastructure**: The system is now containerized using Docker, reverse-proxied behind Nginx, and optimized using Celery Workers and Redis Caching.

## Known Limitations
- The Vision Intelligence engine currently supports 15 major crop diseases. New models will be hot-swapped in v1.1.
- SMS Alerting requires an active Twilio integration which is configured per-tenant.
